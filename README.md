# 一剑一蓑烟雨录

像素风文字武侠 RPG（单页游戏）

## 怎么玩

下载以下 **4 个文件到同一文件夹**，用浏览器打开 `index.html`：

- `index.html` — 页面
- `data1.js` — 地图 + 六大门派
- `data2.js` — 角色 / 武学 / 战力 / 门派逻辑
- `logic.js` — 界面

> 因单文件体积较大，源码拆成 3 个 JS，功能与「完整单文件」完全相同。

## 功能

- 六大门派（拜师、任务、贡献商店、独门武学）
- 15 处可扩展地图（城镇 / 野外 / 门派 / 秘境）
- 战力判定（完胜 / 险胜 / 受挫 / 惨败）
- 武学修炼与突破
